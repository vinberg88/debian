Fix IP problem for X410. Cant find screen problems and other stuff. IP is importent stuff.

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL.

SAVE IP HERE FROM POWERSHELL: 172.30.16.1

GO BACK TO DEBIAN 12 Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo apt install systemd-resolved chatt* e2fsprogs* -y

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip number here and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - Problem fixed for DEBIAN 13 and GNOME desktop via WSL and X410 - 2026

Time to start GNOME desktop via DEBIAN 13.


NOTE: First start x410 and next you start DEBIAN 13 via Terminal.


Paste in terminal: export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2; exit;}'):0.0

Paste in terminal: . ~/.bash_debian_desktop

Paste in terminal: dbus-launch gnome-session


Wait when you start GNOME for the first time via Debian 13 - It will work fine via DEBIAN 13 - But it take some time to start.
